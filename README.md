# Ngozi Arthur Richard Foundation (narfafrica.org)

This archive contains the complete website files for the Ngozi Arthur Richard Foundation:

- `index.html` — All six views (`Home`, `About Us`, `Our Work`, `Our Impact`, `Get Involved`, `News & Updates`) and footer.
- `styles.css` — Layout, typography, responsive breakpoints, and styling.
- `script.js` — View switching, mobile drawer navigation, expandable `SDG Goals` and `Education` accordions, and form validation.

## How to Run
Extract all files into the same folder and open `index.html` in any web browser.
